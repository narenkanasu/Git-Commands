# Git-Commands
To practice Git Commands Exercise 
Git is a distributed version control system used to track changes in source code.

Developed by Linus Torvalds.

Why use Git?
Git helps to:
1. Track code changes.
2. Support team work.
3. Maintains project history
4. Easy backup and recovery.

Important Terms
1. Repository - Storage Capacity
2. Commit - Saved Changes
3. Branch - Separate Development Cycle
4. Clone - Copy Repository

Tip: Git is used locally while GitHub is used on cloud.

Basic Git Workflow
Working Directory --> Staging Area --> Repostiry
